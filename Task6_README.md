# Task 6 — Final Data Science Capstone Project
## EV Charging Demand Analysis and Prediction

**Prepared by:** Monika

### Objective
Analyze EV charging-session data, assess data quality, explore demand patterns, and train a regression baseline to estimate charging demand.

### Files
- `Task6_Capstone_Project.ipynb` — reproducible notebook for data audit, cleaning, exploratory analysis, visualizations, and Random Forest regression.
- `ChargingRecords.csv` — required input dataset, if sharing is permitted. Place it beside the notebook.
- `Task6_Final_Data_Science_Capstone_Report_Monika.docx` — report for the internship portal; upload to GitHub only if you want it versioned there.

### Tools
Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, Jupyter Notebook.

### How to run
1. Install Python and Jupyter.
2. Install dependencies: `pip install pandas numpy matplotlib seaborn scikit-learn`.
3. Place the original `ChargingRecords.csv` file in the same folder as the notebook.
4. Open `Task6_Capstone_Project.ipynb` and run all cells from top to bottom.
5. Use the metrics and charts generated by your run in the final report.

### Important data note
The notebook intentionally does not include a fabricated charging dataset. Results depend on the original CSV provided by the project owner. Check the dataset license and remove personal or sensitive information before publishing it publicly.

### Method
Data quality audit; duplicate and invalid-duration handling; time feature engineering; descriptive statistics; demand distribution and hourly analysis; correlation heatmap; Random Forest regression; MAE, RMSE, R²; actual-vs-predicted and residual plots.

### Limitations
A random holdout is a baseline, not proof of future forecasting performance. Time-based validation, subgroup error analysis, and external validation are recommended before operational use.
